# Recursos de aprendizaje post-201

Recursos útiles para que disfrutes de tu aprendizaje continuo.

## HTML

[Dive Into HTML5](http://diveintohtml5.info/index.html)

Una excelente guía de las nuevas y útiles funciones de HTML5 (canvas, video/audio, local storage y más)

## CSS

[Learn Layout](http://learnlayout.com/)

Una guía paso a paso de las reglas y propiedades importantes para el CSS layout (lo utilizamos en clase)

[SASS Basics](http://sass-lang.com/guide)

La guía oficial de SASS (una poderosa y popular librería de extensiones CSS). Puedes experimentar con él en [Sassmeister](http://www.sassmeister.com/)

## JavaScript

[Eloquent JavaScript](http://eloquentjavascript.net/)

Un excelente libro sobre JavaScript. Revisa los capítulos 1, 2, 3, 4, 6, 13 y 14 para repasar los conceptos y técnicas de Code 201, luego intenta mirar los otros capítulos

[You Don't Know JS](https://github.com/getify/You-Dont-Know-JS)

Una serie de libros cortos que ofrecen análisis profundos y detallados de muchos conceptos importantes de JS.

[A Plain English Guide to JavaScript Prototypes](http://sporto.github.io/blog/2013/02/22/a-plain-english-guide-to-javascript-prototypes/)

Un buen punto de partida si quieres aprender más sobre prototipos y herencia en JS

## Python

[Learn Python the Hard Way](http://learnpythonthehardway.org/)

¿Tienes curiosidad acerca de Python? Esta es una gran serie de ejercicios introductorios

## Ciencias de la Computación

[12 Free Books for Learning Theoretical Computer Science](http://codecondo.com/free-books-theoretical-computer-science/)

Exactamente lo que dice el título. Intenta empezar por aquí si quieres profundizar en temas especializados de CS.
