## Responde
1. ¿Qué es JSON y por qué es importante en el desarrollo web moderno? Explica los métodos `JSON.parse()` y `JSON.stringify()`.
2. ¿Qué es el estado de una aplicación (App State) y cuáles son las mejores prácticas para gestionarlo en JavaScript?
3. Explica cómo funciona el LocalStorage en JavaScript. ¿Cuáles son sus limitaciones y diferencias con SessionStorage?
4. Describe un caso práctico donde implementarías LocalStorage para persistir datos en una aplicación web. ¿Qué tipo de datos guardarías y cómo los recuperarías?
