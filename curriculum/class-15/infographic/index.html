JSON y LocalStorage — Persiste el estado entre sesiones

Serializa objetos a texto con JSON.stringify, guárdalos con localStorage.setItem, y recuperarlos al recargar

1. LocalStorage — 3 métodos para guardar datos en el navegador

Almacenamiento clave-valor en el navegador. Los datos persisten hasta que el usuario los borra — sobreviven recargas y cierres de pestaña.

// Guardar (siempre como string — usa JSON.stringify para objetos)
localStorage.setItem('plantillas', JSON.stringify(array));

// Leer (siempre string — usa JSON.parse para recuperar objetos)
const raw = localStorage.getItem('plantillas');

// Eliminar una clave
localStorage.removeItem('plantillas');
setItem(key, val)
Guardar o sobreescribir valor
getItem(key)
Leer valor (null si no existe)
removeItem(key)
Eliminar una clave

2. JSON — Serialización y Deserialización

LocalStorage solo guarda strings. JSON.stringify convierte objetos a texto. JSON.parse los devuelve a objetos.

Objeto JS
[{nombre: "Ana"}]
JSON.stringify()
→
String JSON
'[{"nombre":"Ana"}]'
JSON.parse()
→
Objeto JS
[{nombre: "Ana"}]
JSON.stringify([{nombre: "Ana", activo: true}]);
// → '[{"nombre":"Ana","activo":true}]'

JSON.parse('[{"nombre":"Ana","activo":true}]');
// → [{nombre: "Ana", activo: true}]

3. Patrón Seguro — JSON.parse siempre dentro de try/catch

JSON.parse lanza un error si el string está corrupto. Envuélvelo siempre en try/catch para que la app no se rompa.

function cargarPlantillas() {
  try {
    const raw = localStorage.getItem('plantillas');
    if (!raw) return [];                          // primera vez
    const datos = JSON.parse(raw);
    if (!Array.isArray(datos)) throw new Error('Datos corruptos');
    return datos;
  } catch (e) {
    console.error(e);
    localStorage.removeItem('plantillas');           // limpiar dato malo
    return [];
  } finally {
    spinner.style.display = 'none';                   // siempre ocultar
  }
}

4. Operador Ternario — Condicional compacto para validaciones

condición ? valorSiTrue : valorSiFalse — ideal para asignaciones simples. Reemplaza un if/else de 4 líneas con 1.

// if/else — 4 líneas
let datos;
if (localStorage.getItem('plantillas')) {
  datos = JSON.parse(localStorage.getItem('plantillas'));
} else { datos = []; }

// Ternario — 1 línea
const raw   = localStorage.getItem('plantillas');
const datos = raw ? JSON.parse(raw) : [];

// Ternario en template literal
elemento.textContent = activo ? "Activo" : "Inactivo";
