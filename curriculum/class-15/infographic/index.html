JSON y LocalStorage — Persiste el estado entre sesiones

Que tus plantillas sobrevivan al recargar: serializa con JSON.stringify, guarda con localStorage y recupéralas al abrir

1. LocalStorage — guardar datos en el navegador

Almacén clave→texto del navegador. Los datos persisten hasta que el usuario los borra: sobreviven recargas y cierres de pestaña.

const CLAVE = "whatsapp-templates";

// Guardar (objeto → texto con JSON.stringify)
localStorage.setItem(CLAVE, JSON.stringify(state.plantillas));

// Leer (devuelve texto, o null si no existe)
const guardado = localStorage.getItem(CLAVE);

// Eliminar la clave
localStorage.removeItem(CLAVE);

2. JSON — serializar y deserializar

localStorage solo guarda texto. JSON.stringify convierte tu array de objetos en texto; JSON.parse lo reconstruye al cargar.

Objeto JS
[{titulo: "Saludo"}]
JSON.stringify()
→
Texto JSON

JSON.parse()
→
Objeto JS
[{titulo: "Saludo"}]
function guardar() {
  // ternario: si no queda nada, borra la clave; si hay, guárdalas
  state.plantillas.length === 0
    ? localStorage.removeItem(CLAVE)
    : localStorage.setItem(CLAVE, JSON.stringify(state.plantillas));
}

3. Cargar seguro — JSON.parse dentro de try/catch

JSON.parse lanza un error si el texto guardado está corrupto. Envuélvelo en try/catch (refuerzo de C12) para que un dato dañado nunca rompa la app.

function cargar() {
  const guardado = localStorage.getItem(CLAVE);
  if (!guardado) return [];              // primera vez: sin datos
  try {
    return JSON.parse(guardado);          // reconstruir
  } catch (error) {
    console.warn("Datos corruptos", error);
    return [];                          // no rompas: lista vacía
  }
}

4. Cuidado: JSON convierte Date en texto

JSON solo guarda datos simples. Un Date se vuelve string al guardarse. Al cargar, rehidrátalo con new Date(...) o .toLocaleDateString() falla.

// p.fecha llega como string tras JSON.parse
// ❌ p.fecha.toLocaleDateString(...)  → error

// ✅ reconstruye el Date al mostrar
const texto = new Date(p.fecha).toLocaleDateString("es-PE");

5. Persistir también el filtro

El filtro (state.filtro) también es parte del estado, así que también se guarda. Pero ya es texto: va directo, sin JSON.stringify, en una segunda clave.

const CLAVE_FILTRO = "whatsapp-templates-filtro";

// el filtro ya es texto: NO necesita JSON.stringify
localStorage.setItem(CLAVE_FILTRO, state.filtro ?? "");

// al arrancar: recupéralo y refléjalo en el buscador
state.filtro = localStorage.getItem(CLAVE_FILTRO) ?? "";
buscador.value = state.filtro;
