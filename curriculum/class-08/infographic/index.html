Tailwind CSS — La interfaz del Gestor

Utility-first, grupos de clases por capas, responsive mobile-first y la conexión del formulario con JavaScript

1. Utility-first — el mismo CSS, dentro del HTML

En vez de escribir reglas en un archivo .css, compones el diseño con clases pequeñas en el HTML. Cada clase equivale a una propiedad CSS que ya conoces de M1.

CSS a mano (M1)
.tarjeta {
  padding: 24px;
  background: white;
  border-radius: 12px;
}
Tailwind (utility-first)
<div class="p-6 bg-white rounded-xl">
  ...
</div>

// mismo resultado, otra notación

2. Dos tipos de clase — vocabulario y gramática

Clase-propiedad: 1 clase = 1 propiedad CSS. Prefijo-modificador: hace que una clase aplique bajo una condición (hover, tamaño de pantalla).

// clase-propiedad — el vocabulario
<p class="text-lg font-bold text-gray-800">

// prefijo-modificador — la gramática
<button class="bg-blue-600 hover:bg-blue-700 md:w-auto">
//                         ↑ al pasar el mouse  ↑ desde tablet

3. Por capas — un grupo de utilidades por vez

Sobre un esqueleto sin estilos, cada parte aplica UN grupo a toda la página. La UI se transforma capa por capa: estructura → aire → estética → adaptación.

P1 Layout       flex · grid · grid-cols-2 · gap-6
P2 Caja         p-6 · mt-4 · w-full · max-w-4xl
P3 Estética     text-3xl · font-bold · bg-white · rounded-xl · shadow
P4 Modificador  hover: · focus: · md:grid-cols-2   (mobile-first)

4. Conectar el Gestor — el formulario funciona

Unas líneas de JavaScript conectan el formulario con tus clases de C07. El Gestor agrega movimientos y actualiza el saldo en vivo: el proyecto del módulo cierra funcionando.

form.addEventListener("submit", function (e) {
  e.preventDefault();
  const nombre = document.getElementById("nombre").value;
  // ...lee tipo y valor...
  presupuesto.agregar(new Movimiento(nombre, tipo, valor));  // ← reusa C07
  render();  // pinta lista + saldo
  e.target.reset();
});
Utility-first Componer el diseño con muchas clases pequeñas en el HTML, en vez de reglas en un .css.
Clase-propiedad 1 clase = 1 propiedad CSS. Ej. text-center = text-align: center.
Prefijo-modificador Hace que una clase aplique bajo una condición: hover:, focus:, md:.
Mobile-first Las clases base son el móvil; md:/lg: agregan estilos para pantallas grandes.
