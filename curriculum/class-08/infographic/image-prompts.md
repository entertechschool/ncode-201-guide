# Image Prompts — Clase 08: Tailwind CSS

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

---

No se requieren imágenes generadas con AI para esta infografía. Los conceptos de utility-first, clase-propiedad vs prefijo-modificador, mejora progresiva por capas y la conexión del formulario con JavaScript son representables con bloques de código y elementos visuales CSS.
