1. ¿Qué es la Programación Imperativa?

Un paradigma que describe CÓMO se hace cada paso. El programa sigue instrucciones secuenciales y exactas — como una receta de cocina.

2. Arrays — La estructura de datos más usada

Una lista ordenada de valores. Se declara con [] y se accede por índice... que arranca en 0, no en 1.

const frutas = ['manzana', 'pera', 'uva'];

frutas.push('mango');      // agrega al final
frutas.length;             // 4 → cuántos hay
frutas[0];               // 'manzana' ← el primero
frutas[frutas.length - 1]; // 'mango'   ← el último
'manzana'
'pera'
'uva'
'mango'

3. Control de Flujo — if · while · for

if valida (con valores falsy), while repite mientras se cumpla una condición, for recorre el array un número conocido de veces.

// if + falsy — valida antes de guardar
if (!nombre || isNaN(monto) || monto <= 0) {
  alert('Datos inválidos.');
  return;
}

// while — repite hasta que el usuario pare
while (continuar === 'si') {
  registrarMovimiento();
  continuar = prompt('¿Otro? (si/no):');
}

// for — recorre el array y acumula
let saldo = 0;
for (let i = 0; i < valores.length; i++) {
  saldo = saldo + valores[i];
}

4. Funciones Imperativas — y su techo

Organizan el código en tareas que leen y modifican el estado global. Punto de partida ideal — pero con un límite natural a medida que el programa crece.

let valores = [];                 // estado global

function registrarMovimiento() {  // modifica global, NO retorna
  // prompt → if → push
}

function calcularSaldo() {        // recorre con for, SÍ retorna
  return saldo;
}
Ventajas
  • Fácil de leer y entender
  • Ideal para scripts pequeños
  • Control total del flujo
Limitaciones
  • Estado global → bugs sutiles
  • Funciones acopladas entre sí
  • Difícil de testear y escalar
