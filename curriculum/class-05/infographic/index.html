Programación Imperativa — Controla el flujo paso a paso

Variables, estructuras de control y funciones para describir exactamente cómo debe ejecutarse cada instrucción

1. ¿Qué es la Programación Imperativa?

Describes CÓMO se hace cada paso. El programa sigue instrucciones secuenciales exactas — como una receta de cocina.

1. capturar input
→
2. validar
→
3. almacenar
→
4. calcular
→
5. mostrar

2. Estructuras de Control

if toma decisiones, while repite mientras se cumpla una condición, for itera un número conocido de veces.

// if — valida antes de guardar
if (nombre && duracion > 0) {
  actividades.push({ nombre, duracion });
} else {
  alert("Datos inválidos.");
}

// while — sigue capturando hasta que el usuario pare
while (continuar) {
  registrarActividad();
  continuar = confirm("¿Registrar otra?");
}

3. Funciones Imperativas — Organizar las instrucciones

Cada función hace una tarea específica y usa el estado global compartido del programa.

let actividades = [];           // estado global

function registrarActividad() {
  let nombre   = prompt("Nombre:");
  let duracion = parseInt(prompt("Minutos:"));
  if (nombre && duracion > 0)
    actividades.push({ nombre, duracion });
}

function calcularTiempoTotal() {
  let total = 0;
  for (let i = 0; i < actividades.length; i++)
    total += actividades[i].duracion;
  return total;
}

4. Ventajas y Limitaciones

El paradigma imperativo es el punto de partida ideal — pero tiene un techo natural a medida que el programa crece.

Ventajas
  • Fácil de leer y entender
  • Ideal para scripts pequeños
  • Sin abstracciones adicionales
  • Control total del flujo
Limitaciones
  • Funciones acopladas a variables globales
  • Difícil de escalar y mantener
  • Repetición de lógica (DRY)
  • Testar es complicado
Paradigma Imperativo Estilo de programación que describe CÓMO ejecutar cada paso de forma secuencial.
prompt() Función del navegador que muestra un cuadro de diálogo para capturar texto del usuario.
Variable global Variable accesible desde cualquier función del programa — compartida por todas.
Función acoplada Función que depende de variables globales o de otras funciones directamente.
