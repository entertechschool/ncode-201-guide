# Image Prompts — Clase 05: Programación Imperativa + Arrays

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

No se requieren imágenes generadas con AI para esta infografía. El paradigma imperativo (flujo secuencial), los arrays (celdas + índice desde 0), las estructuras de control (`if`/`while`/`for`) y las funciones imperativas son todos representables con código resaltado y visuales construidos en HTML/CSS.
