CSS Flexbox — Distribuye y alinea con una sola propiedad

El modelo unidimensional que reemplaza floats, tables y hacks de posicionamiento

1. El Modelo Mental: Main Axis y Cross Axis

Flexbox trabaja en dos ejes perpendiculares. Todo el sistema se reduce a saber en qué eje quieres actuar.

2. Contenedor Flex — justify-content y align-items

display: flex activa el modelo. Las propiedades del contenedor controlan a todos sus hijos.

3. flex-wrap — Diseño Responsivo Sin Magia

flex-wrap: wrap permite que los elementos bajen de línea cuando no hay espacio — la base de las galerías adaptables.

.galeria {
  display: flex;
  flex-wrap: wrap;          /* ← permite múltiples líneas */
  gap: 1rem;
  justify-content: center;
}

4. Propiedades de los Items Flex

Los hijos del contenedor también se configuran — independientemente del resto.

.item {
  flex-grow: 1;         /* crece para ocupar espacio sobrante */
  flex-shrink: 0;       /* no se reduce aunque no haya espacio */
  flex-basis: 200px;    /* ancho base antes de distribuir */
  align-self: flex-end; /* sobreescribe align-items solo aquí */
}

/* Atajo: flex: grow shrink basis */
.item { flex: 1 0 200px; }
Main axis Eje principal del contenedor. Horizontal por defecto (row). Lo controla justify-content.
Cross axis Eje perpendicular al main axis. Lo controla align-items y align-self.
flex-grow Cuánto crece el ítem para llenar el espacio disponible en el main axis.
flex-basis Tamaño base del ítem antes de distribuir el espacio sobrante.
