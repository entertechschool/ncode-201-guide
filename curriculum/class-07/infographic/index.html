POO en JavaScript — Objetos que agrupan datos y comportamientos

Funciones constructoras, this, instancias con new y el primer puente JavaScript ↔ HTML

1. Función Constructora — El molde del objeto

Una función constructora define la forma de un objeto. Cada vez que usas new, JavaScript crea una instancia nueva con sus propias propiedades.

// PascalCase por convención — es una señal visual de "constructor"
function Movimiento(nombre, tipo, valor) {
  this.nombre = nombre;           // propiedad del objeto
  this.tipo   = tipo;
  this.valor  = valor;
  this.fecha  = new Date().toLocaleDateString();

  this.esIngreso = function() {       // método del objeto
    return this.tipo === "ingreso";
  };
}

2. Instanciación — Crear objetos con new

new crea un objeto vacío, vincula this a ese objeto, ejecuta el constructor y retorna el objeto listo para usar.

const salario = new Movimiento("Salario", "ingreso", 3000);
const comida  = new Movimiento("Comida",  "gasto",   200);

salario.esIngreso();   // → true
comida.esIngreso();    // → false

3. Encapsulación — Datos y comportamientos juntos

El objeto Presupuesto guarda sus movimientos y sabe cómo calcular su propio balance.

function Presupuesto() {
  this.movimientos = [];

  this.agregarMovimiento = function(mov) {
    this.movimientos.push(mov);
  };

  this.calcularBalance = function() {
    return this.movimientos.reduce((acc, m) =>
      m.esIngreso() ? acc + m.valor : acc - m.valor, 0
    );
  };
}

4. Primer Puente JS ↔ HTML — Capturar input del form

Con 4 líneas de JS conectas un formulario HTML a tu modelo de objetos. El HTML ya viene listo — solo escribes el JS.

const form = document.querySelector("#form-movimiento");

form.addEventListener("submit", function(event) {
  event.preventDefault();                         // ← evita la recarga
  const nombre = document.querySelector("#nombre").value;
  const tipo   = document.querySelector("#tipo").value;
  const valor  = parseFloat(document.querySelector("#valor").value);
