POO en JavaScript — Objetos que agrupan datos y comportamientos

Objetos, class por capas (propiedades → constructor → métodos), instancias con new y encapsulación

1. Objeto literal — datos con nombre

Cada movimiento pasa de dos arrays paralelos (tipo por signo) a UN objeto con propiedades nombradas. El nombre y el valor viajan juntos: imposible desincronizar.

// ANTES: 2 arrays paralelos · AHORA: 1 array de objetos
let movimientos = [
  { nombre: "Salario", tipo: "ingreso", valor: 3000 },
  { nombre: "Comida",  tipo: "gasto",   valor: 200 }
];

movimientos[0].nombre;   // "Salario" — acceso por nombre

2. class — el molde, por capas

Una clase se construye en 3 capas: propiedades (los datos) → constructor (las pone al crear) → métodos (comportamiento que usa this).

class Movimiento {
  constructor(nombre, tipo, valor) {   // ② las pone al crear
    this.nombre = nombre;              // ① propiedades
    this.tipo   = tipo;
    this.valor  = valor;
  }
  esIngreso() {                        // ③ método
    return this.tipo === "ingreso";
  }
}

3. Instancias con new

new crea un objeto a partir del molde, ejecuta el constructor y lo devuelve listo. Una clase, muchas instancias.

const salario = new Movimiento("Salario", "ingreso", 3000);
const comida  = new Movimiento("Comida",  "gasto",   200);

salario.esIngreso();   // → true
comida.esIngreso();    // → false  ·  sin new → error claro

4. Encapsulación — class Presupuesto

El objeto Presupuesto guarda sus movimientos y sabe calcular su propio saldo. Datos + métodos viven juntos.

class Presupuesto {
  constructor() {
    this.movimientos = [];        // propiedad: el array
  }
  agregar(mov) {
    this.movimientos.push(mov);
  }
