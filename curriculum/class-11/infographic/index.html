async/await, fetch y JSON

La Pokédex consume datos reales de una API

1. JSON — el idioma de las APIs

Texto con la forma de un objeto JavaScript. Es lo que devuelve toda API. response.json() lo convierte en objeto usable.

{
  "name": "pikachu",
  "types": [ { "type": { "name": "electric" } } ]
}
// estructura anidada: distinta a tu objeto limpio → la adaptarás

2. fetch — pedir datos a una URL

fetch devuelve una Promesa (las de C10). Da un response; falta leer su cuerpo para tener los datos.

const response = await fetch("https://pokeapi.co/api/v2/pokemon/pikachu");
// response = la respuesta cruda, NO los datos aún

3. async / await — asincronía legible

async habilita await; await pausa hasta que la promesa resuelve. Dos esperas: que llegue y que se lea.

async function buscarPokemon(nombre) {
  const response = await fetch(url);          // 1. llega
  const data     = await response.json();    // 2. se lee (forma de la API)
  return data;
}

4. Adaptar la estructura de la API

La API entrega otra estructura (anidada). Una función adaptadora la traduce a la limpia de C09, y el render no cambia.

C10 — simulado
new Promise(...)
resolve(pokemonLocal)
.then(render)
C11 — real
await fetch(url)
await response.json()
adaptarPokemon(data)
render([pokemon])
JSON Formato de texto para datos; refleja objetos JS. El idioma de las APIs.

response.json() Convierte el cuerpo JSON en objeto JavaScript.
