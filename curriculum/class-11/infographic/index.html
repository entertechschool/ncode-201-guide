async/await y consumo de APIs

Reformular las promesas, buscar en la API y hacer crecer tu Pokédex

1. De .then a async/await

La misma promesa de C10, escrita como pasos secuenciales. No reemplaza a las promesas: las hace más legibles (azúcar sintáctico).

C10 — .then encadenado
fetch(url)
  .then(r => r.json())
  .then(data => render(data));
C11 — async / await
const r = await fetch(url);
const data = await r.json();
render(data);

2. De filtrar a buscar en la API

El buscador deja de filtrar lo local (tu rejilla) y pasa a consultar la API por nombre: encuentra cualquier Pokémon, aunque no esté cargado.

async function buscarPokemon(nombre) {
  const data = await obtenerPokemon(nombre.toLowerCase());
  return adaptarPokemon(data);   // llega de la API, no de la rejilla
}

3. Capturar: el estado crece

El resultado lleva un botón Capturar. Al pulsarlo, el Pokémon se suma a pokedex (sin duplicar) y la rejilla se vuelve a dibujar. Primer roce con "el estado crece según el usuario".

function capturar(pokemon) {
  if (!pokedex.some(p => p.nombre === pokemon.nombre)) {
    pokedex.push(pokemon);   // la colección crece
  }
  render(pokedex);
}

4. Explorar la respuesta (stats)

La API trae mucho más de lo que usabas (stats, height, weight…). Navegas el JSON anidado y extiendes adaptarPokemon para leer lo que importa.

// antes: name, sprites, types — ahora también:
stats: data.stats.map(s => ({
  nombre: s.stat.name,
  valor: s.base_stat
}))

5. Parámetros: ruta vs consulta

Dos formas de pedirle cosas distintas a una API. El botón "Cargar más" pagina subiendo el offset.

/pokemon/pikachu Ruta — qué recurso quieres
/pokemon?limit=12&offset=24 Consulta — cuántos y desde dónde 
fetch(`...pokemon?limit=12&offset=${offset}`);
offset += 12;   // siguiente página → paginación
async / await Escribir promesas como pasos. await pausa hasta que resuelve.
Filtrar vs buscar Filtrar revisa lo local; buscar va a la API por algo nuevo.
Estado (pokedex) La colección que crece según lo que el usuario captura.
Ruta vs consulta /recurso = qué; ?param = cómo (filtros, paginación).
