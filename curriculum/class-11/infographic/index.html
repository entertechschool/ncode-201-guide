Event Handling — Haz que la página reaccione al usuario

addEventListener registra qué escuchar, el Event Object te dice qué pasó, el callback decide qué hacer

1. addEventListener — La anatomía de un event listener

Tres partes: el elemento que escucha, el tipo de evento y el callback que se ejecuta cuando ocurre.

//    elemento          tipo      callback
//       ↓                ↓           ↓
document.querySelector('#btn').addEventListener('click', function(event) {
  // el callback se ejecuta cada vez que el usuario hace click
  console.log("Clic detectado:", event.target);
});

// Con arrow function (más compacto)
document.querySelector('#btn').addEventListener('click', (e) => {
  e.target.textContent = "¡Hecho!";
});

2. El Event Object — Qué sabe el evento sobre sí mismo

JavaScript genera automáticamente un objeto con información del evento. Lo recibes como parámetro del callback.

document.querySelector('textarea').addEventListener('keydown', function(event) {
  console.log(event.type);      // "keydown"
  console.log(event.target);    // el textarea (elemento que disparó el evento)
  console.log(event.key);       // "Tab", "Enter", "a", etc.

  // Interceptar Tab dentro del textarea
  if (event.key === "Tab") {
    event.preventDefault();     // ← evita que Tab cambie el foco
  }
});

3. El Evento input — Preview en tiempo real

El evento input se dispara con cada tecla. Perfecto para actualizar la vista previa mientras el usuario escribe.

const editor  = document.querySelector('#editor');
const preview = document.querySelector('#preview');

editor.addEventListener('input', function() {
  preview.innerHTML = markdownToHtml(editor.value);
                    // ↑ actualiza con cada keystroke
});

// Contador de palabras en tiempo real
editor.addEventListener('input', () => {
  const palabras = editor.value.trim().split(/\s+/).filter(Boolean).length;
  document.querySelector('#contador').textContent = palabras + " palabras";
});

4. Múltiples Listeners — Un elemento puede escuchar varios eventos

Puedes registrar tantos event listeners como necesites sobre el mismo elemento. No se cancelan entre sí.

const btn = document.querySelector('#limpiar');

btn.addEventListener('click', () => {
  editor.value = '';           // limpia el textarea
  preview.innerHTML = '';    // limpia la preview
});

btn.addEventListener('click', () => {
  document.querySelector('#contador').textContent = '0 palabras';
});

// Ambos se ejecutan. Orden de registro = orden de ejecución.
addEventListener Registra una función callback para que se ejecute cuando ocurra el evento indicado.
event.target El elemento DOM que disparó el evento. Útil para saber qué botón o campo activó la acción.
event.key En eventos de teclado, indica qué tecla se presionó: "Tab", "Enter", "a", etc.
event.preventDefault() Cancela el comportamiento por defecto del navegador para ese evento.
