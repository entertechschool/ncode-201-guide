Funciones y Callbacks — Código modular y reutilizable

Las funciones son valores de primera clase: puedes pasarlas, guardarlas y retornarlas como cualquier dato

1. Funciones de Primera Clase

En JavaScript, las funciones son valores. Puedes asignarlas a variables, pasarlas como argumentos y retornarlas desde otras funciones.

// Asignada a variable
const saludar = function(nombre) { return `Hola, ${nombre}!`; };

// Pasada como argumento
["Ana", "Luis"].forEach(saludar);    // ← saludar es un callback

// Guardada en un array
const formatos = [negrita, cursiva, subrayado]; // funciones como datos

2. Callbacks — Funciones que se pasan como argumento

Un callback es una función que le entregas a otra función para que la llame en el momento apropiado.

// El callback es la función que va dentro de addEventListener
document.querySelector('#btn').addEventListener('click', function(event) {
  // ← esto es un callback: se llama cuando ocurre el click
  procesarFormato(event.target.dataset.formato);
});

// También con arrow functions
document.querySelector('#btn').addEventListener('click',
  (e) => procesarFormato(e.target.dataset.formato)
);

3. Funciones de Orden Superior — Reciben o retornan funciones

Una función de orden superior toma otra función como parámetro y la usa internamente — permite cambiar el comportamiento sin duplicar código.

// La función de orden superior recibe el callback "formatear"
function aplicarFormato(texto, formatear) {
  const seleccion = obtenerSeleccion(texto);
  return texto.replace(seleccion, formatear(seleccion));
}

// Reutilizable con cualquier transformación
aplicarFormato(contenido, texto => `**${texto}**`);  // negrita
aplicarFormato(contenido, texto => `*${texto}*`);   // cursiva

// Sin orden superior: código duplicado para cada formato ❌

4. Modularización — Una responsabilidad por archivo

Separar funciones en módulos hace el código más fácil de leer, testear y modificar sin romper todo lo demás.

format.js
Negrita, cursiva — funciones de formato de texto
lists.js
Conversión de listas numeradas a <ol><li>
blocks.js
Resaltado de bloques de código del editor
app.js
Orquesta e invoca las funciones de los otros módulos
