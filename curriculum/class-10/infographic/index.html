Asincronía y Promesas

Cómo JavaScript maneja datos que tardan en llegar

1. JavaScript no espera

setTimeout programa algo para "más tarde". El programa sigue mientras tanto — no se congela.

console.log("A");
setTimeout(() => console.log("B"), 1000);
console.log("C");

// imprime:  A  C  B   ← la B llega al final

2. Una Promesa — el ticket de un valor futuro

new Promise recibe dos palancas: resolve (llegó bien) y reject (falló).

function obtenerPokemones() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve(pokemonLocal);          // ✅
      // reject(new Error("falló"));   // ❌
    }, 1500);
  });
}

3. Los tres estados

Una promesa empieza esperando y termina en éxito o fallo.

⏳pendingesperando
✅fulfilledresolve(...)
❌rejectedreject(...)

4. Consumir: .then y .catch

.then corre cuando la promesa se resuelve; .catch cuando falla. Dos caminos, siempre cubiertos.

obtenerPokemones()
  .then(lista => render(lista))          // ✅ camino feliz
  .catch(error => mostrarError(error));  // ❌ camino de error
Asincrónico Una operación tarda y el programa sigue trabajando.
setTimeout Ejecuta una función después de N milisegundos.
Promesa Objeto que representa un valor que llegará (o fallará).
.then / .catch Reaccionar cuando el valor llega / cuando falla.
