Datos desde la web: fetch, Promesas y JSON

Cómo JavaScript maneja operaciones que tardan sin bloquear el programa: asincronía, Promesas y el consumo de datos de una API en formato JSON.

1. Asincronía

Una operación asíncrona (red, temporizadores) no detiene el programa. JavaScript la inicia, sigue ejecutando el resto del código y atiende el resultado cuando está listo. El orden de ejecución no es lineal.

console.log("1");
setTimeout(() => console.log("2"), 0); // asíncrono
console.log("3");

// Orden en consola:  1  →  3  →  2

2. Promesa (Promise)

Objeto que representa el resultado futuro de una operación asíncrona. Tiene tres estados: pending (en curso), fulfilled (cumplida) o rejected (fallida). Se consume con .then (resultado) y .catch (error).

// pending  →  fulfilled (valor)
//          →  rejected  (error)

promesa
  .then(valor => { /* fulfilled */ })
  .catch(error => { /* rejected */ });

3. fetch y JSON

fetch(url) realiza una petición HTTP y devuelve una Promesa que resuelve en un objeto Response. JSON es un formato de texto para intercambiar datos; response.json() lo convierte en un objeto JavaScript (y devuelve otra Promesa).

fetch("https://api.ejemplo.com/datos")
  .then(response => response.json()) // JSON → objeto JS
  .then(datos => console.log(datos))
  .catch(error => console.error(error));

4. Promise.all

Recibe un array de promesas y devuelve una sola promesa. Se cumple cuando todas se cumplen y entrega los resultados en orden; se rechaza si alguna falla. Permite ejecutar operaciones asíncronas en paralelo.

Promise.all([promesaA, promesaB, promesaC])
  .then(resultados => {
    // resultados = [valorA, valorB, valorC]
  })
  .catch(error => { /* si una falla, falla todo */ });
Asincronía Modelo en que las operaciones que tardan no bloquean; su resultado se procesa al completarse.
Promesa Objeto con el resultado futuro de una operación asíncrona. Estados: pending, fulfilled, rejected.
fetch Función que hace una petición HTTP y devuelve una Promesa con la respuesta.
JSON Formato de texto para intercambio de datos, basado en objetos y arrays.
