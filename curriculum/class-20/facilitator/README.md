## Notas para el Instructor:

1. Para aprobar, el proyecto debe obtener al menos:
   - 15 puntos en Arquitectura
   - 20 puntos en Funcionalidades Core
   - 10 puntos en Interfaz de Usuario

2. Escala de calificación:
   - Excelente: 90-100
   - Muy Bueno: 80-89
   - Bueno: 75-79
   - Suficiente: 70-74
   - No Aprobado: <70

3. Consideraciones específicas:
   - Verificar que el código no dependa de frameworks externos no autorizados
   - Comprobar que la persistencia de datos funcione correctamente
   - Evaluar la implementación de prototipos y herencia en JavaScript
   - Verificar el manejo correcto de eventos y la manipulación del DOM
   - Comprobar que el diseño sea responsive y funcione en diferentes dispositivos

4. Puntos extra opcionales (máximo 5 puntos adicionales):
   - Implementación de características adicionales útiles
   - Optimizaciones de rendimiento documentadas
   - Pruebas unitarias
   - Implementación de características de accesibilidad
   - Documentación excepcional
