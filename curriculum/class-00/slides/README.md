## Code 201: Fundamentos de Desarrollo Web

### 🎯 Objetivo General

Convertirte en un **Programador con sólidos fundamentos en Algoritmos y Estructura de Datos**,
capaz de construir aplicaciones web interactivas, con pensamiento crítico y apoyo eficiente de herramientas de IA.

#### 🔧 Aprenderás:
- HTML5 y CSS moderno (Flexbox, Grid y Responsividad)
- Programación en JavaScript (imperativa, funcional, OOP)
- Manipulación del DOM, eventos y estado de aplicaciones
- Persistencia local con JSON y LocalStorage
- Proyecto final con enfoque real y validación de usuarios

---

## Estructura:

📅 **Duración total del curso**: 10 semanas (5 módulos)

🧩 **Cada Módulo tiene**: 
- 4 clases en vivo + laboratorios a entregar
- 1 presentación de proyecto + defensa técnica

> 🏁 Evaluación basada en asistencias, participación y entregas.

---

## Módulo 1: Fundamentos de la Web Moderna

🧱 Este módulo sienta las bases visuales y estructurales de la web.

- HTML5 Semántico: accesibilidad y estructura clara
- CSS con Flexbox y Grid: layouts modernos
- Frameworks CSS: estilos reutilizables y escalables

🎯 Enfocado en crear interfaces accesibles, bien organizadas y responsivas.

---

## Módulo 2: Fundamentos de Programación

🧠 Aquí empieza el verdadero poder del código.

- Programación imperativa: instrucciones paso a paso
- Programación funcional: funciones puras, map, filter
- OOP en JavaScript: objetos, clases, encapsulamiento

🎯 Desarrollarás una mentalidad algorítmica y capacidad de estructurar lógica reutilizable.

---

## Módulo 3: Aplicaciones Web con Objetos

📦 Aplicarás los fundamentos a la creación de interfaces dinámicas.

- Prototipos en JS: herencia basada en objetos
- Funciones, callbacks y asincronía básica
- DOM como API de Objetos
- Manipulación dinámica del DOM

🎯 Aprenderás cómo crear interactividad real desde cero.

---

## Módulo 4: Eventos y Persistencia

🔄 Haz que tu app "recuerde" y responda como un sistema real.

- Manejo de eventos (event listeners)
- Estado de la app (App State)
- JSON como formato universal de datos
- LocalStorage y sincronización

🎯 Habilitarás persistencia sin servidor, clave en apps modernas.

---

## Módulo 5: Proyecto Real

🚀 Desarrolla una aplicación real de principio a fin.

- Ideación + Investigación
- Sprint 1 + Validación con Usuarios
- Iteración + Demo Final

🎯 Pondrás a prueba todo lo aprendido con acompañamiento técnico y feedback continuo.

🔍 Evaluación: funcionalidad, código limpio, experiencia de usuario y presentación técnica.

---

## ¿Cómo son las clases y cuánto dura el curso?

> 🕒 **Cada clase dura 3 horas (180 min)** y sigue esta estructura:

- 🔥 **Introducción:** conexión con la clase anterior y contexto (15 min)
- 💬 **Demo Inicial y Debate:** ejercicios de refuerzo y activación del debate (30 min)
- 🛠️ **Laboratorio:** ejercicios guiados con checkpoints (120 min)
- 🧠 **Síntesis y cierre:** reflexiones y conclusiones finales (15 min)

> 👉 **Debes llegar a cada clase con conceptos técnicos repasados**.

- ⏳ Se espera 1 hora de preparación autónoma previo a cada clase.

---

## Evaluación y Promedio final

📅 **Duración total del curso**: 10 semanas
🧩 5 módulos → 4 clases por módulo + 1 presentación de proyecto
🧪 Evaluación basada en participación, entregas y defensa técnica

🎯 Aprenderás haciendo, debatiendo y construyendo soluciones reales desde el día 1.
