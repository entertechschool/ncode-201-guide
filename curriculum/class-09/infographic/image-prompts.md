# Image Prompts — Clase 09: JavaScript Moderno y Render Dinámico

> Prompts para generar imágenes con AI. Cada imagen corresponde a un `<img src="...">` en `index.html`.

---

**No se requieren imágenes.** Toda la infografía es representable en HTML/CSS (código resaltado, comparativa antes/después y glosario), por lo que `index.html` no contiene ningún `<img src="...">`.
