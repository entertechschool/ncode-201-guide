DOM como API de Objetos — Manipula el HTML con JavaScript

Cada etiqueta es un nodo-objeto. Selecciónalo, modifícalo y transforma su contenido con Regex

1. El DOM — Árbol de objetos vivos

El navegador convierte el HTML en un árbol de objetos. Cada etiqueta es un nodo con propiedades (.textContent, .classList) y métodos (.addEventListener).

2. La Familia de APIs del DOM

Una API por intención: selección, clases, estilos y transformación de texto. No las mezcles.

APIPara qué
querySelector('sel')Trae el primer elemento que matchea — o null
querySelectorAll('sel')Trae todos los elementos → NodeList iterable
classList.add/remove/toggle()Modifica clases CSS del elemento
style.propiedad = 'valor'Aplica estilo inline desde JavaScript
texto.replace(/regex/g, '...')Transforma strings con expresiones regulares
// ← 1 elemento | todos → ←
document.querySelector('#btn').textContent = 'Hecho';
document.querySelectorAll('h2').forEach(h => h.classList.toggle('highlight'));

3. Regex — Transforma Markdown a HTML con replace()

El método replace() con expresiones regulares convierte texto Markdown en etiquetas HTML reales.

function markdownToHtml(texto) {
  return texto
    .replace(/^## (.+)$/gm, '<h2>$1</h2>')  // primero ## (más específico)
    .replace(/^# (.+)$/gm,  '<h1>$1</h1>')  // luego #
    .replace(/^- (.+)$/gm,  '<li>$1</li>'); // listas
}
// Flag /g → reemplaza TODOS los matches, no solo el primero
// Flag /m → ^ y $ matchean inicio/fin de cada línea

En lugar de un componente predefinido como .card, combinas utilidades pequeñas directamente en el HTML. Total control, cero CSS propio.
