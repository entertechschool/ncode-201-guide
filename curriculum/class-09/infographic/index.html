JavaScript Moderno y Render Dinámico

La idea que sostiene toda app web: los datos mandan y el HTML es su reflejo. La sintaxis ES6+ son las herramientas para lograrlo.

1. La idea central — los datos mandan

En una app moderna no escribes el HTML a mano: lo generas desde datos. La pantalla es el reflejo de un array — cambian los datos, vuelves a dibujar. El patrón siempre es el mismo: limpiar → recorrer → crear → agregar.

// Datos  →  render()  →  UI en pantalla
function render(lista) {
  contenedor.innerHTML = "";               // 1. limpia
  lista.forEach(pokemon => {
    const tarjeta = crearTarjeta(pokemon); // 2. crea
    contenedor.appendChild(tarjeta);        // 3. agrega
  });
}

2. Template literals — el molde de HTML

Para convertir un dato en HTML necesitas un molde de texto con huecos. Los backticks insertan valores con ${...} y permiten varias líneas: por eso reemplazan la concatenación con +.

Concatenación (vieja)
"<h2>" + nombre + "</h2>"
Template literal
`<h2>${nombre}</h2>`

3. Preparar los datos — destructuring + map

Antes de dibujar, extraes lo que necesitas (destructuring) y transformas listas en HTML (map + join). Es acomodar los datos para la vista.

// extraer: de un objeto a tres variables
const { nombre, imagen, tipos } = pokemon;

// transformar: cada tipo → un badge
tipos.map(tipo => `<span>${tipo}</span>`).join("");

4. Datos reales = datos con huecos

Cuando los datos vienen de afuera, no siempre están completos. El código debe sobrevivir a lo que falta: ?. accede sin romper y ?? pone un valor de respaldo.

// ?. : acceso seguro si el dato no existe
const cuantos = pokemon.tipos?.length ?? 0;

// ?? : respaldo si falta la imagen
const img = pokemon.imagen ?? "placeholder.png";
Render dinámico Generar el HTML desde datos, no a mano. La UI es el reflejo del array.
Template literal String con backticks e interpolación ${...}. El molde para construir HTML.
Destructuring Sacar propiedades a variables: const { nombre } = pokemon.
Optional chaining obj?.prop accede sin romper si el dato falta.
