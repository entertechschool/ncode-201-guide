Sintaxis ES6+, generar HTML desde datos y la base de la Pokédex

1. Template literals — construir HTML legible

Strings con backticks que insertan valores con ${...} y permiten varias líneas. Reemplazan la concatenación con +.

Concatenación (vieja)
"Hola, " + nombre + "!"
Template literal
`Hola, ${nombre}!`

2. El patrón render — la UI refleja los datos

Limpiar el contenedor → recorrer los datos → crear un nodo por cada uno y agregarlo. Cambias el array y la pantalla cambia, sin tocar el HTML.

function render(lista) {
  contenedor.innerHTML = "";               // 1. limpia
  lista.forEach(pokemon => {
    const tarjeta = crearTarjeta(pokemon); // 2. crea
    contenedor.appendChild(tarjeta);        // 3. agrega
  });
}

3. Destructuring — datos limpios

Sacas las propiedades de un objeto a variables en una sola línea, sin repetir pokemon. por todos lados.

// de un objeto a tres variables
const { nombre, imagen, tipos } = pokemon;

// tipos como badges: map + join
tipos.map(tipo => `<span>${tipo}</span>`).join("");

4. Acceso seguro: ?? y ?.

Los datos a veces tienen huecos. ?? da un valor de respaldo; ?. accede de forma segura a algo que podría no existir, sin romper el programa.

// ?? : respaldo si falta la imagen
const img = pokemon.imagen ?? "placeholder.png";

// ?. : acceso seguro si el dato no existe
const cuantos = pokemon.tipos?.length ?? 0;
