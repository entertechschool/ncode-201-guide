Interacción y datos derivados

Un solo listener para todo, CRUD inmutable y orden con .sort()

1. Delegación de eventos

Un solo listener en el contenedor padre atiende los clics de todas las tarjetas. Según en qué hijo se hizo clic (event.target), decide la acción. Sobrevive a cada render().

lista.addEventListener("click", (e) => {
  const id = e.target.dataset.id;
  if (e.target.classList.contains("btn-eliminar")) eliminarPlantilla(id);
  if (e.target.classList.contains("btn-editar"))   cargarEnFormulario(id);
});

2. CRUD inmutable

Eliminar y editar sin tocar el array original: .filter crea uno sin el elemento; .map + spread crea uno con la plantilla actualizada en su lugar.

Eliminar — .filter
state.plantillas =
  state.plantillas
    .filter(p => p.id !== id);
Editar — .map + spread
state.plantillas =
  state.plantillas.map(p =>
    p.id === id ? { ...p, titulo } : p);

3. Datos derivados (función pura)

El total y el conteo por hashtag no se guardan: se calculan del estado en cada render(). Una función pura recibe el estado y devuelve el resultado, sin tocar nada más.

function contarPorHashtag(plantillas) {
  return plantillas.reduce((conteo, p) => {
    conteo[p.hashtag] = (conteo[p.hashtag] ?? 0) + 1;
    return conteo;
  }, {});
}

4. Ordenar con .sort()

.sort() usa un comparador (a, b): negativo si a va antes, positivo si va después. Muta, por eso copiamos con [...] antes.

const copia = [...plantillas];   // no mutar el estado

// alfabético: copia.sort((a, b) => a.titulo.localeCompare(b.titulo));
// recientes:  copia.sort((a, b) => new Date(b.fecha) - new Date(a.fecha));
Delegación de eventos Un listener en el padre decide según event.target.
data-id / dataset Guarda el id en el HTML; se lee con e.target.dataset.id.
Función pura Recibe datos y devuelve un resultado, sin efectos externos.
Comparador Función (a, b) que dice quién va primero en .sort().
