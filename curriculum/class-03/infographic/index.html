CSS Grid + Flexbox — Layouts responsivos reales

Lo mínimo de Grid que necesitas + las propiedades profundas de Flex + media queries verificadas

1. Grid vs Flex — Cuándo usar cada uno

La decisión es simple: Flex controla una sola dimensión. Grid controla filas y columnas al mismo tiempo.

2. Grid Esencial — El patrón del 80%

Con solo 3 propiedades resuelves casi todas las grillas de tarjetas que necesitarás.

.testimonios {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 columnas iguales */
  gap: 1rem;                              /* espacio entre filas y columnas */
}

3. Flexbox Profundo — flex-basis y align-self

Las propiedades de los ítems permiten que cada elemento tenga su propio comportamiento dentro del mismo contenedor.

.compra   { display: flex; flex-wrap: wrap; gap: 1rem; }

.producto { flex-basis: 400px; flex-grow: 1;        }
.resumen  { flex-basis: 250px; align-self: flex-start; }
.extras   { flex-basis: 100%;                        }

/* align-self sobreescribe align-items solo para ese ítem */

4. Media Queries — El cambio que el usuario debe notar

Un breakpoint sin cambio visual observable no sirve. Siempre verifica con DevTools modo responsive.

@media (max-width: 768px) {
  .testimonios { grid-template-columns: 1fr;     }
  .compra      { flex-direction: column;        }
}

fr unit Fracción del espacio disponible en el contenedor grid. 1fr 1fr = dos columnas iguales.
flex-basis Tamaño base del ítem antes de distribuir el espacio sobrante con flex-grow.
align-self Sobreescribe align-items del contenedor para un solo ítem específico.
breakpoint Punto de quiebre en @media donde el layout cambia para adaptarse al viewport.
