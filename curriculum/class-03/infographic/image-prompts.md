## grid-vs-flex.png

Diagrama comparativo dividido verticalmente en dos mitades. La mitad izquierda muestra **CSS Grid (2D)**: una cuadrícula de 3×2 con filas y columnas visibles, etiquetada "Grid — 2D: filas y columnas". La mitad derecha muestra **CSS Flex (1D)**: una fila de 4 cajas alineadas horizontalmente, etiquetada "Flex — 1D: una dirección". Ambas mitades tienen el mismo fondo oscuro. Las etiquetas de sección ("Grid — 2D" y "Flex — 1D") deben estar claramente visibles arriba de cada diagrama.

**OBLIGATORIO (colores):**
- Fondo: #0d1117
- Texto/labels: #e2e8f0
- Elementos del lado Grid (celdas y bordes): #d946ef (púrpura) — representa 2D
- Elementos del lado Flex (cajas y borde): #4ade80 (verde) — representa 1D
- Línea divisoria central: #475569

**PROHIBIDO:**
- Fondo blanco o claro
- Colores fuera de la paleta (#d946ef, #4ade80, #93c5fd, #fb923c)
- Texturas, gradientes 3D, elementos decorativos
- Sombras excesivas

**GRAYSCALE (todo lo demás):**
