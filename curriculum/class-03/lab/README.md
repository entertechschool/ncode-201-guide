# Lab 03: Web moderna con flexbox, box-model

## Descripción General
En este laboratorio, crearás una página web moderna y responsiva que muestre información sobre tecnologías web. El diseño debe adaptarse tanto a dispositivos móviles como a escritorio, implementando un diseño profesional y atractivo.

## Instrucciones 
1. Estructura HTML
   - Implementa una barra de navegación con dos enlaces: "GitHub" y "README".
   - Agrega a la etiqueta `main` un contenedor `div` que contendra las tarjetas informativas.
   - Cada tarjeta debe incluir:
      - Una imagen (utiliza placehold.co para generar imágenes de 400x200 píxeles).
      - Un encabezado de segundo nivel (`<h2>`).
      - Un párrafo descriptivo.
      - Un enlace "Ver más".
        
2. Imágenes
   - Para las imágenes de las tarjetas:
      - Utiliza el servicio `placehold.co`
      - Dimensiones requeridas: 400x200 píxeles.
      - Ejemplo de URL: `https://placehold.co/400x200`
      - Asegúrate de incluir un atributo `alt` descriptivo para cada imagen.

3. Estilos CSS
   - Diseño de Navegación:
      - Debe tener un color de fondo, utiliza el más adecuado.
      - Los enlaces deben ser blancos y en negrita.

4. Diseño de Tarjetas:
      - Fondo blanco.
      - Bordes redondeados.
      - Sombra suave.
      - La imagen debe cubrir el ancho completo manteniendo sus proporciones.
      - Espaciado interno adecuado para el contenido.
      - Botón "Ver más" con efecto `hover`.

5. Diseño Responsivo:
   - Móvil: tamaños menores a 600px 
      - Las tarjetas deben ocupar el ancho completo.
      - La navegación debe estar fija en la parte inferior.
   - Escritorio: tamaños mayores a 600px
      - Las tarjetas deben organizarse en una grilla.
      -  La navegación debe estar fija en la parte superior.
   

## Logros adicionales

- Utiliza la familia de fuentes 'Segoe UI' con respaldo del sistema.
- Implementa un fondo gris claro para el body.
- Asegúrate de que el contenido sea scrolleable.
- Mantén márgenes y espaciados consistentes.
