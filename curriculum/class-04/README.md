# Clase 04: Frameworks CSS Modernos

## Resumen
En la Clase 04 se exploran los frameworks **Bootstrap** y **Tailwind CSS** como herramientas clave para estilizar interfaces web. Además, aprendemos a gestionar las ramas en **Git**, consolidando habilidades para trabajar en equipo y organizar código de manera modular.

### Podrán hacer
1. **Estilizar Interfaces Web con Frameworks Modernos**  
   Aplicar Bootstrap para secciones convencionales y Tailwind CSS para diseños más personalizados.

   Crear y fusionar ramas para organizar el desarrollo del proyecto.

   Justificar la elección de cada framework según las necesidades del proyecto.

1. **Diseño Consistente y Personalizable**

   Desarrollar en ramas dedicadas, realizar Pull Requests y fusionar el código en la rama principal.

## Glosario de Nuevos Términos

- **Component Class:** Clases predefinidas para elementos visuales como botones y tarjetas.
- **Utility Class:** Clases individuales que permiten ajustes rápidos de diseño.
- **Rama (Branch):** Línea independiente de desarrollo en Git para trabajar en funcionalidades específicas.
- **Pull Request:** Solicitud para fusionar cambios de una rama a la principal tras su revisión.
- **Merge:** Proceso de integración del código de diferentes ramas en una única línea de desarrollo.
