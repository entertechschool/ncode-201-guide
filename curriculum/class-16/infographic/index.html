Persistencia y Sincronización — Estado guardado que actualiza la UI sola

Guardado automático, Store ↔ UI en tiempo real, confirmaciones UX y delegación de eventos

1. Guardado Automático — Persistir en cada cambio de estado

Integra el guardado en LocalStorage dentro de setState. Cada cambio en el estado persiste automáticamente.

const store = {
  state: { plantillas: [] },
  listeners: [],

  setState(newState) {
    this.state = newState;
    localStorage.setItem('plantillas',          // ← guardado automático
      JSON.stringify(newState.plantillas)
    );
    this.notify();
  },
  /* getState, subscribe, notify como en C14 */
};

2. Sincronización — Siempre render desde el estado, nunca desde el DOM

La UI es un reflejo del Store. Nunca leas el DOM para conocer el estado — pregunta al Store. Nunca actualices el DOM directo — actualiza el Store y que él re-renderice.

function render(state) {
  lista.innerHTML = state.plantillas
    .map(p => `<li data-id="${p.id}">${p.titulo}</li>`)
    .join('');
  contador.textContent = `${state.plantillas.length} plantillas`;
}

store.subscribe(render);     // ← registrar UNA vez
render(store.getState());    // ← render inicial al cargar

// ✅ Cada setState dispara render automáticamente.
// ❌ Nunca: lista.innerHTML = lista.innerHTML + '...'

3. Confirmaciones UX — Proteger acciones críticas

Antes de eliminar un dato permanentemente, muestra una confirmación visual. El usuario debe confirmar — no asumir.

function eliminarPlantilla(id) {
  if (!confirm("¿Eliminar esta plantilla? No se puede deshacer.")) {
    return;  // el usuario canceló — no hacer nada
  }

  store.setState({
    ...store.getState(),
    plantillas: store.getState().plantillas.filter(p => p.id !== id)
  });
  // El Store persiste y re-renderiza automáticamente
}

4. Delegación de Eventos — Un listener para N botones hijos

En lugar de añadir un listener a cada botón dinámico, coloca uno en el contenedor padre. Captura todos los clicks con event.target.

// ❌ Un listener por botón — rompe con listas dinámicas
document.querySelectorAll('button.eliminar').forEach(btn =>
  btn.addEventListener('click', () => eliminar(btn.dataset.id))
);

// ✅ Un listener en el contenedor — funciona para todos
lista.addEventListener('click', function(event) {
  if (event.target.classList.contains('eliminar')) {
    eliminarPlantilla(event.target.dataset.id);
  }
  if (event.target.classList.contains('editar')) {
    abrirEditor(event.target.dataset.id);
  }
});
