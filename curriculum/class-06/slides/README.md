## Programación Funcional en JavaScript

---

## 🪝 Conectando con lo que aprendimos...

- ¿Recuerdas los problemas que tuviste al modificar directamente variables globales o arrays en la clase pasada?
- ¿Te imaginas una manera más limpia y segura de gestionar el estado en tu proyecto?

---

## 🎯 Objetivos

- Comprender el paradigma funcional y su diferencia con el paradigma imperativo.

- Aplicar funciones puras para resolver tareas específicas.

- Utilizar funciones de orden superior para transformar datos.
  - `map()`, `filter()` y `find()`.

---

## 💬 Debate + 🖥️ Demo Técnica  

- ¿Qué ventajas concretas ofrece la programación funcional frente a la imperativa?

- ¿Cómo ayudan las funciones puras y los métodos funcionales (`map`, `filter`, `find`) a mejorar el código?

- Veamos esto en acción con ejemplos prácticos en JavaScript.

---

## ☑️ Checkpoint 1  
**Funciones puras y uso de `map()`**

- Crea funciones puras para manipular arrays.
- Utiliza el método `map()` para extraer datos específicos sin modificar el array original.

---

## ☑️ Checkpoint 2

- Usa `filter()` para obtener elementos según una condición (por ejemplo, egresos mayores a un valor específico).

- Usa `find()` para localizar rápidamente elementos por una propiedad concreta (ejemplo: nombre del gasto).

---

## 💡 Conclusiones clave de la clase:

- La programación funcional promueve claridad, predictibilidad y calidad del código.

- La inmutabilidad facilita las pruebas unitarias y el debugging.

- Funciones puras y métodos funcionales son herramientas esenciales para proyectos reales y profesionales.
