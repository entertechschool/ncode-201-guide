Programación Funcional — Transforma datos sin efectos secundarios

Arrow functions, funciones puras y los métodos map / filter / reduce para reemplazar el for por código predecible y testeable

1. Arrow Functions — La forma corta

Sintaxis compacta para escribir funciones. La verás en TODO código JS moderno — sobre todo como argumento de otros métodos.

// Forma "function" (la que ya conoces)
function duplicar(valor) {
  return valor * 2;
}

// Arrow function — equivalente, más corta
const duplicar = valor => valor * 2;
// sin function, sin llaves, sin return

2. Función Pura — La base del paradigma

Es pura si: (1) mismo input → mismo output, siempre, y (2) no produce efectos secundarios. Por eso son fáciles de testear y razonar.

// ✅ PURA — solo depende de su parámetro
const cuadrado = valor => valor * valor;

// ❌ IMPURA — depende de variable externa
let factor = 10;
const escalar = valor => valor * factor;

// ❌ IMPURA — produce un efecto
const imprimir = valor => console.log(valor);

3. map · filter · find — Transformar y filtrar

Tres métodos que recorren un array y devuelven datos nuevos sin mutar el original. Reemplazan al for para transformar y buscar.

const valores = [3000, -45.50, 500, -30];

valores.map(valor => valor / 4);    // [750, -11.37, 125, -7.5]
valores.filter(valor => valor > 0); // [3000, 500]
valores.find(valor => valor < 0);   // -45.50  (no array)

4. reduce — El más poderoso

Acumula todo el array en un solo valor (suma, máximo, promedio...). Reemplaza el for de C05 en una sola línea.

const saldo = valores.reduce((acumulador, valor) => acumulador + valor, 0);

5. Declarativo vs Imperativo — QUÉ vs CÓMO

La programación funcional describe QUÉ queremos lograr. La imperativa describe CÓMO hacerlo paso a paso. El for de C05 desaparece.

// IMPERATIVO — describe cada paso
let ingresos = [];
for (let i = 0; i < valores.length; i++) {
  if (valores[i] > 0) ingresos.push(valores[i]);
}

// FUNCIONAL — describe el resultado deseado
const ingresos = valores.filter(valor => valor > 0);
Función pura Mismos inputs → mismo output. No modifica estado externo ni produce efectos secundarios.
Efecto secundario Cualquier acción fuera del retorno: console.log, mutar variables externas, hacer fetch.
Inmutabilidad No modificar datos existentes. Los métodos funcionales devuelven copias transformadas.
Composición / DRY Combinar funciones pequeñas para construir grandes, sin repetir código.
