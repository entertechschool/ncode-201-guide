Programación Funcional — Transforma datos sin efectos secundarios

Funciones puras, inmutabilidad y métodos map / filter / find para código predecible y testeable

1. Funciones Puras vs Impuras

Una función pura siempre devuelve el mismo resultado para los mismos argumentos y no modifica nada fuera de ella.

// ❌ IMPURA — modifica variable externa (efecto secundario)
let total = 0;
function sumarImpuro(valor) {
  total += valor;     // ← modifica estado externo
  return total;
}

// ✅ PURA — solo depende de sus parámetros
function sumarPuro(totalActual, valorNuevo) {
  return totalActual + valorNuevo;  // ← sin efectos secundarios
}

2. map() — Transforma cada elemento

map() recorre el array y retorna un nuevo array del mismo tamaño con los elementos transformados. El original no cambia.

const movimientos = [
  { nombre: "Salario",   valor: 3000 },
  { nombre: "Freelance", valor: 500  },
];

const nombres = movimientos.map(mov => mov.nombre);
// → ["Salario", "Freelance"]

const montos  = movimientos.map(mov => mov.valor * 1.18);
// → [3540, 590]  ← array original intacto

3. filter() y find() — Filtrar y buscar

Ambos buscan por condición, pero retornan cosas distintas: filter devuelve todos los que cumplen, find solo el primero.

const movs = [
  { nombre:"Salario",   tipo:"ingreso", valor:3000 },
  { nombre:"Comida",    tipo:"gasto",   valor:200  },
  { nombre:"Freelance", tipo:"ingreso", valor:500  },
];

// filter() → array con TODOS los que cumplen
const ingresos = movs.filter(movimiento => movimiento.tipo === "ingreso");
// → [{ Salario… }, { Freelance… }]

// find() → el PRIMER elemento que cumple (o undefined)
const salario  = movs.find(movimiento => movimiento.nombre === "Salario");
// → { nombre:"Salario", tipo:"ingreso", valor:3000 }

4. Declarativo vs Imperativo — QUÉ vs CÓMO

La programación funcional describe QUÉ queremos lograr. La imperativa describe CÓMO hacerlo paso a paso.

// IMPERATIVO — describe cada paso
let ingresos = [];
for (let i = 0; i < movs.length; i++) {
  if (movs[i].tipo === "ingreso")
    ingresos.push(movs[i]);
}

// FUNCIONAL — describe el resultado deseado
const ingresos = movs.filter(movimiento => movimiento.tipo === "ingreso");
Función pura Mismos inputs → mismo output. No modifica estado externo ni produce efectos secundarios.
Inmutabilidad No modificar datos existentes. Crear copias transformadas en su lugar.
Efecto secundario Cualquier modificación fuera del scope de la función: console.log, mutar variables globales.
Composición Combinar funciones simples para construir funciones más complejas.
