Clases y Estado — Modela objetos con estructura y propósito

La sintaxis class organiza datos y comportamientos. El estado es el "momento actual" del objeto

1. Sintaxis class — constructor + métodos

La clase define la estructura. El constructor inicializa el estado. Los métodos definen el comportamiento que puede cambiarlo.

class Tarea {
  constructor(titulo) {
    this.titulo     = titulo;  // estado local
    this.completado = false;  // estado inicial
  }

  completar() {              // método que modifica el estado
    this.completado = true;
  }

  mostrarEstado() {
    return `${this.titulo}: ${this.completado ? "✓" : "pendiente"}`;
  }
}

// class es azúcar sintáctica — internamente sigue usando prototipos (C08)

2. Estado Local vs Estado Global

El estado local pertenece a una instancia. El estado global es compartido por toda la aplicación.

Estado Local (de la instancia)
  • Propiedades this.x del constructor
  • Solo accesible desde ese objeto
  • Cada instancia tiene el suyo
  • Ejemplo: tarea1.completado
Estado Global (de la app)
  • Arrays o variables fuera de clases
  • Compartido por toda la aplicación
  • Cualquier función puede leerlo
  • Ejemplo: const tareas = []

3. Múltiples Instancias — Estado Independiente

Cada new crea un objeto con su propio estado. Cambiar uno no afecta al otro.

const t1 = new Tarea("Diseñar mockup");
const t2 = new Tarea("Implementar API");

t1.completar();              // solo t1 cambia

console.log(t1.completado); // → true
console.log(t2.completado); // → false  ← intacto
t1 (instancia 1)
titulo: "Diseñar mockup"
completado: true
t2 (instancia 2)
titulo: "Implementar API"
completado: false

4. Encapsulamiento — Los métodos controlan el estado

En lugar de modificar propiedades desde afuera, usa métodos. Esto protege el estado de cambios incorrectos.

class Usuario {
  constructor(nombre) {
    this.nombre = nombre;
    this.tareas = [];              // estado encapsulado
  }

  agregarTarea(titulo) {         // ← acceso controlado
    this.tareas.push(new Tarea(titulo));
  }

  tareasCompletadas() {
    return this.tareas.filter(t => t.completado).length;
  }
}

const user = new Usuario("Ana");
user.agregarTarea("Revisar código");
// user.tareas.push(x) funciona pero rompe el encapsulamiento

constructor() Método especial que se ejecuta al crear una instancia con new. Inicializa el estado.
