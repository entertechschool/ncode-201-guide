String y Date — Modela datos y transforma texto

Gestor de Plantillas para WhatsApp: del estado central al mensaje final

1. Estado central → render()

Modelas cada plantilla con class y guardas todo en un único estado. La regla de oro: cambias el estado → llamas render(), que limpia y redibuja todo.

const state = { plantillas: [] };  // la verdad de la app

function render() {
  lista.innerHTML = "";        // limpia
  state.plantillas.forEach(p => /* dibuja cada una */);
}
cambias el estado
→
render()
→
pantalla actualizada

2. Métodos de String

Un texto es un objeto con métodos. Ojo: no mutan el original, devuelven un texto nuevo (hay que reasignar).

.trim()quita espacios de los bordes
.toLowerCase()todo a minúsculas (unifica)
.startsWith("#")¿empieza con...? (true/false)
.split(" ")parte el texto en una lista
.slice(0, 40)recorta un trozo del texto
hashtag = hashtag.trim().toLowerCase(); // "  VENTAS " → "ventas"

3. Mensaje final: sustituir variables

La plantilla trae marcadores como {nombre}. Con .replaceAll() los cambias por un valor real: una plantilla, mil mensajes.

"Hola " + "{nombre}, gracias"
  .replaceAll("{nombre}", "Ana");
// → "Hola Ana, gracias"

replaceAll cambia todas las apariciones; replace solo la primera.

4. Date: fecha de creación

new Date() captura el momento exacto. .toLocaleDateString("es-PE") lo vuelve texto legible para mostrarlo.

this.fecha = new Date();        // al crear la plantilla
p.fecha.toLocaleDateString("es-PE"); // "29/6/2026"

Normalizar trim + toLowerCase para que variantes queden iguales.
