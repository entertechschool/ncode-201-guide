# Code 101 - Elementals Software Development

Un estudiante que ha llevado este curso (previo a Code 201) sale con una base sólida en los siguientes puntos:

1. Fundamentos Web: El estudiante comprende la estructura y el flujo de la web, y sabe utilizar HTML para organizar el contenido, CSS para dar estilo y JavaScript para agregar interactividad.

2. Entorno de Desarrollo: Maneja herramientas esenciales como la línea de comandos (CLI), editores de código, Git y GitHub para el versionamiento y la colaboración. Conoce la configuración básica de un entorno de desarrollo para proyectos web.

3. Programación Elemental en JavaScript: Domina conceptos iniciales de la sintaxis del lenguaje, variables, operadores, condicionales, bucles y funciones. Además, aprende a manipular el DOM para crear experiencias dinámicas y responder a eventos de usuario.

4. Wireframing y Maquetación: Entiende los principios de maquetación y diseño mediante wireframes, así como la importancia de una estructura semántica en HTML y la aplicación de layouts en CSS.

5. Uso de IA en Desarrollo: Explora cómo aprovechar herramientas de inteligencia artificial, como ChatGPT, para mejorar y optimizar la escritura de código, gestionando prompts y contextos.

6. Control de Versiones y Flujo Colaborativo: Comprende la importancia de trabajar con repositorios, ramas y pull requests en GitHub, incluyendo la resolución de conflictos y la documentación con Markdown.
