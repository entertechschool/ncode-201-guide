- Conocimientos básicos de lógica de programación

## Flujo extraordinario:
- Examen de admisión

### Examen de Admisión
Es un examen de 20 preguntas técnicas que comprueba la aprobación de los requisitos previos necesarios para iniciar en Code 301.
Tiene una duración de 90 minutos y se programa anticipadamente con el Director Académico de Enter Tech School.

#### Modo de Evaluación:
- Plataforma Canvas.
- 100 puntos totales (5 puntos por pregunta).
- Puntuación mínima para aprobar: 70 puntos.

#### Temas a evaluar:

**Bloque 1: HTML5 y CSS Layouts**
- HTML semántico vs. divs genéricos
- Accesibilidad web y lectores de pantalla
- Flexbox: propiedades del contenedor y comportamiento de `flex-shrink`
- CSS Grid: `grid-template-columns`, `grid-template-areas`, unidades `fr`
- Media queries y diseño responsivo
- Atributos ARIA y elementos nativos accesibles

**Bloque 2: Fundamentos de JavaScript**
- Control de flujo: bucles `for`, `while`, condicionales
- Métodos de array: `filter()`, `map()`, `find()`, `reduce()`
- Funciones puras vs. funciones con efectos secundarios
- Funciones constructoras: `function`, `this`, `new`
- Prototipos: `Constructor.prototype`, herencia

**Bloque 3: DOM y Event Handling**
- Selección de elementos: `querySelector()` vs. `querySelectorAll()`
- Manipulación del DOM: `createElement()`, `appendChild()`, `textContent`
- Event listeners: `addEventListener()`, objeto `event`, `event.target`
- Callbacks: funciones como argumentos
- Manejo de excepciones: `try`, `catch`, `finally`, `throw`

**Bloque 4: Estado y Persistencia**
- Clases ES6: `class`, `constructor`, métodos
- JSON: `JSON.stringify()` y `JSON.parse()`
- LocalStorage: `setItem()`, `getItem()`
- Serialización de objetos y arrays para almacenamiento
- Patrón de recuperación de datos persistentes

#### Materiales / Recursos:
- Computadora con navegador web moderno (Chrome recomendado)
- Conexión a internet estable
- Acceso a la plataforma Canvas
