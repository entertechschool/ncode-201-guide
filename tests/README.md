Tienes intentos ilimitadas en los Tests.
Los Tests son a libro abierto. Se trata más de lo que puedes descubrir que de lo que has memorizado. Siéntete libre de utilizar recursos como tu consola de desarrollo, Google, Stack Overflow y otros, mientras realizas pruebas.
Los Tests tienen dos propósitos principales:
Conseguir que vuelvas a involucrarte con el contenido de una manera diferente, reforzando tus conocimientos.
Ayudar a prepararte para el examen de ingreso al Code 301, que realizarás al final del Módulo 3. 
Existe un umbral mínimo que debes aprobar en ese examen (80%) y, además, ese examen influye en tu calificación en este curso.
