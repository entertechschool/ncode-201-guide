### Analizando la abstracción en este código, ¿qué opción es correcta?
```javascript
class CuentaBancaria {
    private saldo: number;
    
    depositar(monto: number) {
        this.saldo += monto;
    }
    
    obtenerSaldo() {
        return this.saldo;
    }
}
```
