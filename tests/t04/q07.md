### En el siguiente código POO, ¿qué principio se está aplicando?
```javascript
interface Volador {
    volar(): void;
}

class Pajaro implements Volador {
    volar() {
        console.log("El pájaro vuela");
    }
}

class Avion implements Volador {
    volar() {
        console.log("El avión vuela");
    }
}
```
